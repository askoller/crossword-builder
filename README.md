# Crossword Builder

A mobile-first crossword construction app for foldable Android phones: grid editor with
its own keyboard, fill suggestions, autofill (whole grid or selected squares), duplicate
checks, clue history and a notebook, all offline in the browser.

This repository contains only code. Word lists, scores, clue data and puzzles are
imported by the user at runtime and never stored here.
